# Aegis Core v1.1 Full Stack Gates

## Frontend invariant guard

The inspect_source function and differential review gate now cover .js, .jsx,
.ts, .tsx, .mjs, .cjs, and inline script blocks in .html files. Findings
include the repository relative path, physical source line, domain, severity,
and the nearest statically named function where one is visible. The scanner
blanks comments and strings before matching code, then reads request options
from the original source text to keep offsets stable.

The frontend checks cover request timeouts and abort signals, unbounded retry
loops, risky numeric inputs and divisions, resource cleanup, growing
collections, JSON and storage failures, floating promises, dynamic code
execution, unsafe HTML insertion, and direct prototype mutation. These checks
are deterministic lexical guards. They report visible high risk patterns and
do not claim to prove arbitrary JavaScript control flow or the runtime origin
of every value.

## Runtime profiler sampling

RuntimeProfiler still executes the target command in a child process and
stores only names, types, shapes, and source locations. Repeated call edges use
a signature of caller, callee, call site, and argument schema SHA-256. Lines,
returns, exceptions, and dynamic getattr observations are similarly folded
by site. A deterministic reservoir samples novel signatures up to
max_events; repeated hits update counts without spending additional slots.

Profiles retain the v1 fields and add unique_event_count, reservoir_size,
reservoir_replacements, dropped_unique_site_count, and reservoir_sample.
The legacy event_count and event_limit_reached fields report the saturated
raw observation volume for compatibility; they do not mean repeated events
were discarded. unique_event_limit_reached reports when novel site volume
exceeds the reservoir budget.

## Read-only fleet preflight

Run aegis audit-fleet --owner Xiaoyu155 to inspect repositories containing
remote branches named feat/aegis-*. The command reads GitHub metadata and
refs, fetches only the default and delivery refs into a temporary bare Git
repository, calculates merge-base diffs, and invokes git merge-tree
--write-tree without updating refs. It writes:

Use --exclude-repo repeatedly to skip a repository during a fleet pass, for
example when another delivery window owns that repository.

- artifacts/fleet_dashboard_v16.json — structured audit ledger
- artifacts/fleet_dashboard_v16.md — one-page merge and risk dashboard

Conflicts and unrelated histories are P0. Sensitive path names or unusually
large changes are P1. Other mergeable branches are P2. The
default_branch_zero_pollution field verifies that no commit unique to the
delivery branch is reachable from the default branch; it does not infer
whether equivalent changes were copied by squash or manual edits.
