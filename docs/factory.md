# Factory PR4

Offline grammar is finite: literal function-call expectations and market circuit
contracts. Unsupported wishes suspend rather than silently invent assertions.
Online compile requires configured endpoints and synthesizes a test-only patch.
Worktrees isolate files, not hostile processes. Never use this on untrusted test
code without an OS isolation layer. HTTP repair is syntax-only and cannot infer
missing values. Budget units are conservative bytes; no tokenizer dependency.
Graph resolution is static; reflection, monkeypatching and runtime dispatch may
remain unresolved. Concurrency tests are bounded evidence, not a proof that no
filesystem/database can ever lock. Dataset variants are explicitly synthetic.
