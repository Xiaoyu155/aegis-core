# Aegis Core v1.2 Precision Gates

## Invariant noise filter

`inspect_source` still returns raw source findings, now annotated with a confidence
grade (`CRITICAL`, `HIGH`, `MEDIUM`, or `SUPPRESSED_NOISE`), confidence score,
asset type, scope, and a suppression reason. The path classifier excludes known
vendor, test, offline tooling, documentation example, and static prototype
locations. Resource warnings are suppressed only when the matching resource is
released from a recognized framework lifecycle hook. Mini-program request
warnings account for platform default timeouts; repository mini-program timeout
configuration and configured HTTP client defaults are also read as static text.

`scan_changed_files` keeps suppressed findings for auditability but only returns
unsuppressed findings in `findings`. It includes both sets in `summary`, with a
noise-reduction rate. This is a lexical analysis and does not establish runtime
taint or independently labeled vulnerability truth.

## PR fleet shipper

```bash
aegis ship-fleet --owner Xiaoyu155
aegis ship-fleet --owner Xiaoyu155 --exclude-repo org/repo
```

The command defaults to a read-only dry run. It emits one submit-ready title and
body per delivery branch, with commit history, diff totals, CI state, merge
preflight, risk priority, review checklist, and an idempotency key. Open PRs are
reused. `--execute` requires a GitHub token in `GITHUB_TOKEN`; only deliveries
with green checks and a clean conflict preflight are created. `nova-agent`,
`Checkpoint`, and `edu-typing` are excluded by default.

Local repositories can be previewed without GitHub access:

```bash
aegis ship-fleet --repo ../service-a --repo ../service-b --base-branch main
```

## World-model calibration

```bash
aegis world-model-bench --repo . --out artifacts/world_model_calibration.json
```

Tournament winner/loser patches and causal traces are split by group so paired
examples cannot cross the train/validation boundary. The benchmark reports the
false-positive block rate, false-negative rate, recall, and patch-line-based
compute-savings estimate at each threshold. A threshold is eligible only when
the held-out false-positive block rate is strictly below 1% and recall is at
least 85%. The report cannot authorize `observe -> enforce` without an
`AEGIS_CALIBRATION_SIGNING_KEY` of at least 16 bytes; eligible permits use
HMAC-SHA256 and can be checked with `verify_permit`.
