# Crucible V2 freeze

V1 PR remains open: this is a stacked change on feat/aegis-core-v1.
No unavailable whitepaper or historical examples are asserted as recovered facts.

Mediator proposal fields: target_files, contract_stub (Python signatures/docstrings
and ellipses only). Questions carry kind/ticket_id/status/questions; each question
has code/question/options/recommended. Each option has id/label/value. Never ask
for secret values: credential availability is an attestation plus a reference.
Production execution requires credential_ref; finance requires explicit bounded
max_drawdown, max_notional and position_mode; destructive migrations require an
explicit allowlist and rollback boundary. Ambiguity <0.15 requires selection.
Store every compiled/missing state and reward through the V1 ledger transaction.

Router models.yaml is JSON syntax (a YAML 1.2 subset), so no PyYAML dependency.
Deadlines use monotonic absolute time in one process; transport receives remaining
time after verify reserve. Quotas and breaker state are in-process, thread-safe.
Slots share concurrency_group for one GPU. Two consecutive exact rejected-patch
hash repeats quarantine a slot; escalate, otherwise blocked_needs_human.
No billing, credentials or availability claims are inferred from model labels.

Reward: gate +1 iff both probes verified, -0.5 iff baseline failed/final failed,
else -1. Jaccard(empty,empty)=0. Concise=max(0,1-diff_lines/budget),
latency=clamp(elapsed/budget,0,1), cheat/repeat penalty=1 once. Clip [-2,1.5].

Fixtures are offline, original Python simulations of user-specified invariants,
not copies of real JavaScript game or trading deployment source. Export includes
raw transitions plus messages/prompt/completion/group_id and stable fixture hashes;
QLoRA/GRPO training itself is outside stdlib control-plane scope.
