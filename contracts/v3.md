# Combined stages 3/4 contract freeze

Base is PR #2; no existing PR #3 or training assets are assumed. Preserve all
existing tests and V2 data. Add 12 executable fault modes. Build 520 mediator SFT
examples split 468/52 and 520 GRPO candidate rows in 260 paired groups. Execute
both patch outcomes for each fault template; expanded instruction variants cite
those template measurements and are explicitly synthetic, not 520 independent
executions. SFT target answers are revalidated by the deterministic compiler.

CLI contract manifests pin repository HEAD, targets, frozen stub, trusted probe
argv and source directories. run uses a fresh worktree per attempt and shared
router state for replay detection. Offline patch candidates require no model.
Model network/CLI execution is explicit opt-in. Every attempt/terminal decision
is a WAL causal transition. Exports remain compatible with V1 JSONL. Stats use
terminal tickets for success rate and repair-attempt traces for cheat count and
mean reward. Missing questions can resume the same ticket after constraints.

Training is optional and isolated: QLoRA uses 4-bit NF4, batch 1, short sequences
and checkpointing defaults. GRPO online reward evaluates generated patches in
the frozen offline fixtures, never trusts model-provided rewards. No claim of
8GB feasibility or GPU training completion without measurement. Invalid or
missing CUDA/bitsandbytes support must fail explicitly, never silently switch
to full precision. Bootstrap installs training only when explicitly requested.
