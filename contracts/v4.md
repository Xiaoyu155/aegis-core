# PR4 freeze

Offline rules cover explicit finite domains; unsupported wishes stop for input.
Probe generation is a test compiler, not a language-complete theorem prover.
Generated tests are additive, test-only, frozen before workers see the task.
Repair-only diffs are checked against the frozen probe baseline; workers cannot
modify the probe. A red probe is verified before any model repair dispatch.
PRECHECK_FAILED is terminal and recorded with full feedback, including malformed
manifests for known tickets. Hash mismatch cannot alter another worker's ticket.
AST indexing is static, excludes generated/vendor directories, reports decoding
and resolution diagnostics; budget is a conservative UTF-8 byte upper bound.
Retry clocks/sleep/jitter are injectable; bounded response repair never invents
missing semantic values. Worktrees remain trusted-process file isolation.
Datasets cite executed templates and retain augmentation provenance. No fake
physical evidence or model/GPU measurements are generated.
