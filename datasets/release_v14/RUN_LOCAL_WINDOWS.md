# Aegis v14 local training bundle

Windows 11 + RTX 5060 8GB: run `scripts\bootstrap_local.ps1` from the repository root.
SFT dataset: `datasets\sft_train.jsonl`; GRPO preferences: `datasets\grpo_preference_pairs.jsonl`.
Base model and tokenizer: `Qwen/Qwen2.5-Coder-3B-Instruct`. The release uses the tokenizer recorded in the manifest.
